# Tarball download-window 2 versus 4

Thirty randomized paired rounds on the same locked React/Vite fixture. Fresh projects and Jhol caches, harvest disabled, 7,610,763 downloaded bytes per run. All 60 samples passed route and scoped package/runtime/lock quality checks. Registry and OS caches were uncontrolled. Jhol release SHA-256: `6739eb1f845bc1e3187adda65408b224e7345ce150d7bafc2c77da0530202daf`.

| Window | Median | p95 | Valid samples |
|---:|---:|---:|---:|
| 2 | 1,219.91 ms | 1,634.10 ms | 30/30 |
| 4 (current default) | 1,025.08 ms | 1,549.09 ms | 30/30 |

Paired median elapsed ratio (2/4) was 1.153; paired bootstrap 95% CI [1.046, 1.240]. Lowering the window to 2 was slower. Retain default 4. Raw paired samples and runner inputs are in the adjacent JSON report. This is Jhol-only tuning, not a Bun comparison or 4× claim.
