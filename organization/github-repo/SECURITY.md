# Security policy

Do not report vulnerabilities in a public issue. Send a private report to
**bhuvanstark6@gmail.com** with enough detail to reproduce the issue safely.
Do not include real credentials, customer data, or private registry contents in
the report.

The main repository's [security policy](https://github.com/bhuvanprakash/jhol/blob/main/SECURITY.md)
has the current supported-version statement and disclosure guidance. Until an
organization handle is established, it remains the source of truth.
