# Jhol site

User-facing home for Jhol's product story, onboarding, and tutorials. The main
`jhol` repository remains authoritative for command behavior, schemas, and
engineering contracts.

Every installation command and feature claim on the site must name a release
or be checked against the current source. Keep compatibility limits visible.
Explain Jhol in its own voice: local-first package work, verified outcomes, and
coordination through native ecosystem tools. Do not imitate another project's
branding, page design, wording, or unsupported claims.
