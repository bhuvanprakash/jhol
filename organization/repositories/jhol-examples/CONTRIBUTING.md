# Contributing examples

Keep examples small enough to inspect and runnable with a documented release
of Jhol. State required native tools, network access, platform limits, setup,
cleanup, and the verification command. Preserve ecosystem-native manifests and
lockfiles so readers can see which tool owns each result.

Do not present planned or unavailable behavior as working. Avoid real
credentials, personal data, and unnecessary network services; use disposable
fixtures and explain any generated files.
