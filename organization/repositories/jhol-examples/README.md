# Jhol examples

Runnable projects showing what a named Jhol release supports. Each example
states its required Jhol version, native tools, network needs, and verification
command.

Examples should make one workflow clear at a time: JavaScript installation,
native lockfile interop, Python or Rust coordination, database planning, or
verified model artifacts. Keep language-native manifests and lockfiles intact.
Mark unavailable services and platform requirements plainly. Prefer small
fixtures that users can inspect and run locally.
