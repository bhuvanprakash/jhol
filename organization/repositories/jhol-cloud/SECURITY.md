# Security policy

Report cloud-service vulnerabilities privately to **bhuvanstark6@gmail.com**;
do not open a public issue containing exploitable details. Include affected
service and revision, impact, and a safe reproduction. Never send live tokens,
customer content, or private object keys in a report.

Reports involving cross-tenant access, credential exposure, corrupted cache
content, or quota bypass should identify the affected tenant boundary without
including another tenant's data.
